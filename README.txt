موقع مكتبة الأزهري
====================
الملفات:
- index.html الصفحة الرئيسية
- services.html الخدمات
- books.html الكتب والأدوات

- contact.html التواصل
- style.css التصميم

ملاحظة: مكان اللوجو الحالي رمزي (📚). عند إرسال اللوجو الأصلي يمكن استبداله بسهولة.

للنشر المجاني: ارفع محتويات هذا المجلد إلى خدمة استضافة مواقع ثابتة مجانية مثل GitHub Pages أو Cloudflare Pages.
